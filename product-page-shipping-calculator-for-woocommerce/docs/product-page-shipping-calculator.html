Introduction

Product Page Shipping Calculator shows available shipping methods and costs directly on the WooCommerce product page.

Customers enter a delivery location and see which shipping methods apply, without adding the product to the cart or going to checkout. Results appear without a page reload.

Getting Started

Step 1: Open the settings

Go to:

WooCommerce > Shipping Calculator

The settings page has these tabs:

  • Basic setting
  • Design
  • Remove fields
  • Popup
  • Labels
  • Estimate date / Show estimate delivery date

Step 2: Configure the basic options

Open the Basic setting tab. Set where the calculator appears, how results load, and how quantity is handled. Open the Labels tab to set button text and messages customers see.

Step 3: Save the settings

Click Save Changes.

Quick Start

For a basic setup:

  1. Set Position of the calculator on product page to After add to cart button.
  2. Set Shipping calculator form default state to Closed by default.
  3. Set Auto calculation of shipping method to Enabled.
  4. Click Save Changes.

Customers can then click Select delivery location, enter an address, and see shipping methods for that address.

Plugin Features

  • Show shipping methods and costs on the product page.
  • Let customers change delivery location and see updated methods.
  • Place calculator before or after Add to cart button, or with shortcode.
  • Control where results appear.
  • Auto-load results or require manual update.
  • Support cached product pages.
  • Respect product quantity or ignore it.
  • Show single-product cost ignoring rest of cart.
  • Customize button texts and result messages.
  • Remove unneeded address fields.
  • Customize design template and button colors.
  • Disable calculator for specific products.
  • Support variable products.
  • Support delivery location popup flow under Popup tab.

Plugin Settings

Position of the calculator on product page

Controls where the calculator appears on the product page. Found under Basic setting.

What to select:

  • After add to cart button - shows calculator after the Add to cart button. This is the default.
  • Before add to cart button - shows calculator before the Add to cart button.
  • Use shortcode [pi_shipping_calculator] to insert manually - stops automatic output. Add [pi_shipping_calculator] manually on the product page.

Example: Choose shortcode mode and add [pi_shipping_calculator] to the product page content when automatic position does not fit your theme.

Shortcode works only on product pages. It shows an error when shortcode mode is not enabled. It does not show for virtual or out-of-stock products.

Position of the calculator result

Controls where the calculated result appears. Found under Basic setting.

What to select:

  • Before "Calculate Shipping" button - default.
  • After "Calculate Shipping" button
  • Before shipping form (hidden container) - inside the collapsible form.
  • After shipping form (hidden container) - inside the collapsible form.

Shipping calculator form default state

Controls whether the address form starts expanded or collapsed.

  • Closed by default - default. Customer clicks the button to expand the form.
  • Open by default - form is visible when page loads.

Auto calculation of shipping method

Controls whether results load automatically.

  • Enabled - default. Shipping methods load automatically.
  • Disabled - automatic loading is skipped. Customer must click Update Address. Before calculation, the message from When user hasn't entered an address is shown.

Load user location data via AJAX

Use this when the product page is cached. The saved customer location is loaded dynamically instead of from cached page content.

When to use it: Enable it if caching causes wrong customer location to appear.

Product Quantity Field

Controls whether the quantity selected on the product page affects the estimate.

  • Calculate for 1 unit until the product is in the cart - default. Uses 1 unit when product is not in cart. When product is already in cart, uses cart quantity.
  • Calculate for the quantity selected (more accurate) - uses quantity from product page plus quantity of same product already in cart.

Example: Customer sets quantity to 3. With Calculate for the quantity selected (more accurate), estimate uses 3 plus any same product already in cart.

Show shipping cost of the individual product only

When enabled, other products in the cart are ignored during calculation. Result reflects only the product being viewed.

When to use it: Enable when viewed product has different shipping cost than rest of cart and you want isolated estimate.

Example: Cart has product B. Customer views product A. With this enabled, result shows cost for product A only.

When user hasn't entered an address

Found under Labels tab, section Product page calculator labels. Message shown when no location is entered yet, or when auto-loading is disabled and no calculation ran.

Default: Insert your location to get the shipping method

Button – Calculate Shipping

Found under Labels tab, section Product page calculator labels. Text inside button that opens the calculator form.

Default: Select delivery location

Button – Update Address

Found under Labels tab, section Product page calculator labels. Submit button inside address form.

Default: Update Address

Above the shipping method list

Found under Labels tab, section Product page calculator labels. Heading shown above list of available methods.

Default: Shipping methods available for your location:

What to enter: You can use [country] to show selected country name.

Example: Enter Shipping methods available for [country]:. If customer selects India, heading reads Shipping methods available for India:.

When no shipping methods are available

Found under Labels tab, section Product page calculator labels. Message shown when location is entered but its shipping zone has no methods.

Default: No shipping methods available for your location

When no product variation is selected

Found under Labels tab, section Product page calculator labels. Used on variable products before variation is chosen. Calculator stays hidden until in-stock, non-virtual variation is selected.

Default: Select variation

If left empty, no message is shown.

Price next to free shipping methods

  • No price is shown - default. Free methods keep normal WooCommerce label.
  • Show "0" - shows 0 price next to free method.

Remove address form fields from product page calculator

Found under Remove fields tab. Each is on/off. Default is off, meaning field is shown.

  • Remove country field
  • Remove state field
  • Remove Town/City field
  • Remove Postcode/Zip field

Important: If your shipping zones depend on a field, do not remove it. Zone matching will fail.

Country field rule: Country dropdown is removed only when store ships to exactly one country and Remove country field is enabled. When store ships to more than one country, this option is not available.

The same tab has separate options for the popup address form. Those affect popup form only, not product-page calculator.

Design template

Found under Design tab.

  • Template 1 - default.
  • Old classic template

Box showing result of shipping methods

Found under Design tab.

  • Background color of shipping methods - default light peach gradient.
  • Text color of message - default black.
  • Text color of shipping methods name - default black.
  • Text color of shipping charges - default black.

Button colors

Found under Design tab.

  • Calculate shipping button background color
  • Calculate shipping button text color - default white.
  • Update address button background color
  • Update address button text color - default white.

Disable shipping cost per product

Found at Products > Edit product > Shipping calculator.

Setting: Disable shipping cost

  • Select option - no change.
  • Disable calculator - hides calculator for that product.
  • Enable calculator - keeps calculator enabled for that product.

Calculator also does not show for virtual products. Tab is not shown for grouped products.

Important Notes

  • WooCommerce must be active. Without it, plugin shows admin notice and stops loading.
  • Set WooCommerce > Settings > Default customer location to Shop base address or geolocation option for reliable results. Empty value triggers admin warning on plugin settings screen.
  • Do not remove a form field that shipping zones depend on. Zone matching will fail.
  • Remove country field works only when store ships to single country. For multi-country stores, option is disabled with notice.
  • Default selected country comes from customer shipping country. Single-country stores can auto-select it.
  • Price and tax display follow WooCommerce tax settings.
  • For variable products, customer must select variation first. Out-of-stock or virtual variations keep calculator hidden.
  • Estimate date tab needs Estimate Delivery Date plugin. Without it, that tab shows install instructions instead of working settings.

FAQ

Where is the calculator positioned?

Under Basic setting > Position of the calculator on product page: before or after Add to cart button, or manually with [pi_shipping_calculator].

Where is the result positioned?

Under Basic setting > Position of the calculator result. Four positions: before or after Calculate Shipping button, or before or after shipping form inside hidden container.

How is quantity handled?

See Product Quantity Field. Use Calculate for the quantity selected (more accurate) when shipping cost depends on quantity.

Can calculator ignore rest of cart?

Yes. Enable Show shipping cost of the individual product only.

Can a single product opt out?

Yes. Edit product, open Shipping calculator tab, set Disable shipping cost to Disable calculator.

Does it work for variable products?

Yes. Customer must select variation first. When no product variation is selected message covers unselected state.

Why is country removal unavailable?

That option works only when store ships to single country. Set WooCommerce > Settings > General > Shipping location(s) to one country first.

Troubleshooting

Calculator does not appear on a product

Check per-product Shipping calculator setting is not Disable calculator, check product is not virtual, and check Position of the calculator on product page.

Shortcode shows an error

Position of the calculator on product page must be set to Use shortcode [pi_shipping_calculator] to insert manually, and shortcode must be on product page.

Wrong location loads from cache

Enable Load user location data via AJAX.

Result ignores quantity field

Set Product Quantity Field to Calculate for the quantity selected (more accurate).

Result reflects other cart items

Enable Show shipping cost of the individual product only.

No methods for valid address

Check WooCommerce > Settings > Shipping > Shipping zones has matching zone with at least one method, and check removed fields are not needed for zone matching.
